# Workshop 02 진행자 안내

## 진행 목표

WS1의 외부 기능 연결 경험을 이어 받아, 이미 있는 앱을 로컬에서 실행하고 작은 변경을 검증·기록·복구합니다. WS1 미참여자는 starter로 참여합니다. 2~3인 그룹에서 조작자와 확인자를 번갈아 맡습니다.

## 사전 준비

- 행사 일시·장소·협력단체·예산·혜택·신청 링크는 미정. 확정되지 않은 조건은 홍보문에 넣지 않습니다.
- 행사 약 14일 전: 확정 정보와 슬라이드·brief를 묶어 제출. 이는 이번 준비 목표이며 공식 확정 마감으로 간주하지 않습니다.
- D-7: 참가자 사전 설치 안내, GitHub Fork·Clone·Codex 로그인 점검.
- D-2: 운영진 PC와 참가자용 일반 계정에서 실습 리허설. 강의실 인터넷·전원 점검, 시작본·완성본을 오프라인 확보.
- 시작 15분 전: 실행 화면 확인, Git 작성자 설정 확인, 복구 연습 준비 명령 실행. 설치가 끝나지 않은 참가자는 준비된 팀원의 기기를 함께 사용합니다.

## 60분 진행

| 시간 | 진행 | 완료 증거 |
| --- | --- | --- |
| 00–05 | 체크인·조 편성, 시작본/완성본 빠른 시연 | 오늘 바꿀 기능 한 줄 |
| 05–12 | 파일·터미널·브라우저, Git/GitHub 구분, 실행 확인 | starter 화면 |
| 12–22 | Codex 요청 → diff → 클릭 검증 → commit·push 시연 | 같은 commit을 GitHub에서 확인 |
| 22–45 | 참가자 실습: 요청 5분, 수정 13분, 검증 5분 | 선택·해제·독립 상태·초기화 |
| 45–50 | 변경 파일 선별, commit·push | 본인 Fork의 commit |
| 50–55 | 독립 저장소에서 revert | 버튼 복구 + 새 commit |
| 55–60 | 짝과 30초 공유, 체크아웃·후속 안내 | 결과 한 줄과 저장소 주소 |

## 10번 슬라이드의 60초 시연

1. 루트에서 npm run dev. 시작본을 열고 즐겨찾기 버튼이 없는 상태를 보여줍니다.
2. 완성본에서 카드 A·B 선택 → A 해제. B가 유지되는지 함께 봅니다.
3. 새로고침하면 선택이 초기화됨을 보여줍니다. 저장 기능은 WS3에서 연결합니다.
4. 이 화면은 실제 실행 예제입니다. 영상이 필요한 경우 이 순서를 60초 녹화하되 영상은 필수 자료가 아닙니다.

## 막혔을 때

- 설치·인증: 준비된 팀원 기기로 합류. 한 명은 요청, 한 명은 검증 담당.
- Codex 사용 불가: 운영진 시연과 complete의 diff를 함께 읽고 검증·Git 실습 진행. AI 직접 사용 미완료는 기록.
- 실행 중 5173 포트 충돌: 기존 서버를 Ctrl+C로 종료한 뒤 한 서버만 실행.
- push 오류: origin·브랜치·GitHub 로그인 확인. 미해결이면 로컬 commit까지만 기록, Studio Hour로 이어감.
- 시간 부족: 개인 확장 과제·branch/PR은 후속 과제로 넘기고 필수 클릭 검증 유지.
- 복구 연습: 로컬 독립 저장소임을 강조. 상위 원본 저장소를 되돌리지 않도록 현재 경로 확인.

## 제출 전 확인

일시·장소·정원·신청 방법·예산·참가 혜택·협력단체 명칭 및 동의, 자료 접근 권한을 확정합니다. 현재 모두 미정인 항목은 실제 확답 후에만 바꿉니다. 슬라이드와 brief의 시간이 같은지 확인합니다.
