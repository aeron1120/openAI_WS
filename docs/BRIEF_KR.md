## 행사 목적 및 학습 목표

- 학생들의 필요: 처음 만든 앱을 계속 개선하려면 기능을 작게 나누어 요청하고, 직접 검증하고, 변경 기록을 남기는 방법이 필요합니다.

- 주제 선정 이유: WS1의 외부 기능 연결에서 이어져, 로컬 개발 환경·Codex 활용·Git/GitHub를 작은 기능 수정 하나로 경험합니다.

- 결과물: 앱 로컬 실행, 즐겨찾기 선택·해제 검증, commit·push 및 본인 GitHub 기록 확인, 별도 연습 저장소에서 revert 후 동작·이력 복구 확인.

- 협업 단체: 미정. 참여 확답과 명칭 사용 동의를 받은 단체만 기재합니다.

## 활동 및 OpenAI 도구 활용

- 활동: 캠퍼스 모임 플래너 시작본·완성본을 비교한 뒤 Codex로 카드별 즐겨찾기를 추가하고 직접 눌러 검증·기록합니다. 준비된 참가자는 자신의 프로젝트에 같은 흐름을 적용합니다.

- Campus Hub 템플릿: 자체 커리큘럼. [aeron1120/openAI_WS](https://github.com/aeron1120/openAI_WS)에 시작본·완성본·복구 실습 제공. 현재 비공개이며 배포 전 접근 권한 조정 필요.

- 사용 도구: Codex로 프로젝트 파악·기능 수정·오류 해결, ChatGPT로 요청 구체화. 보조 도구는 VS Code·Node.js·Git·GitHub입니다.

- 시연 방식: 요청 → 변경 파일·diff → 클릭 검증 → commit → push → GitHub 확인. 복구는 별도 연습 저장소에서 비활성화된 버튼을 되돌립니다. 즐겨찾기는 새로고침 시 초기화하며 영구 저장은 WS3에서 다룹니다.

## 행사 준비 사항

- 참가자: 노트북·충전기, 사용 가능한 Codex/ChatGPT·GitHub 계정, VS Code·Git·Node.js 20 이상 사전 설치. 본인 Fork·Clone과 로컬 실행을 완료하고 수정할 기능 한 가지 준비.

- 행사장 및 장비: 프로젝터와 스크린, 노트북용 멀티탭, 안정적인 Wi-Fi, 운영진이 자리 사이를 다닐 수 있는 좌석 배치

- 운영진: 계정·자료 접근 확인, 시작본·완성본·복구 예제 리허설과 오프라인 사본 준비. 시작 15분 전 설치 지원, 준비가 안 된 참가자는 팀원과 함께 실습.
