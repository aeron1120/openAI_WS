# 지도·위치정보 구현하기

서비스에 필요한 장소를 지도에서 보여주는 기능입니다. 장소 검색, 모임 위치, 캠퍼스 시설 안내 등에 사용할 수 있습니다.

## 준비

- 수정할 곳: `starter/index.html`의 `map` 영역.
- Google Maps JavaScript API를 사용합니다. 지도 키는 결제 정보 없이 받는 [지도 데모 키](https://developers.google.com/maps/demo-key?hl=ko)를 씁니다.
- 데모 키 받기:
  1. 지도 데모 키 페이지에서 **데모 키 가져오기**를 누릅니다.
  2. 개인 Gmail 계정으로 로그인합니다. 학교·회사(Google Workspace) 계정은 받을 수 없어요.
  3. 약관에 동의하면 키가 바로 보입니다. 키를 복사합니다.
- 하루 한도를 넘으면 다음 날까지 멈출 뿐 요금은 나오지 않아요. 키를 넣는 곳은 [지도 설정 문서](../docs/MAPS.md)를 보세요.

## Codex 요청문

```text
starter의 지도·위치정보 영역에 Google 지도를 구현해줘.
서울대학교 정문 위치에 마커를 표시하고,
마커를 누르면 장소 이름이 보이게 해줘.
지도 키는 결제 없이 받은 지도 데모 키, Map ID는 DEMO_MAP_ID를 쓸 거야.
docs/MAPS.md를 참고해 키를 넣을 위치와 확인 방법을 안내해줘.
좌표는 확인한 실제 위치를 사용해줘.
```

## 내 아이디어로 바꾸기

- 서울대학교 정문을 내 서비스에서 필요한 장소로 바꿉니다.
- 여러 장소가 필요하면 “장소 목록에서 선택할 때 지도와 마커도 이동하게 해줘”라고 이어서 요청합니다.
- **사용자의 현재 위치**는 별도 기능입니다. 필요할 때만 “위치 사용에 동의하면 현재 위치를 보여주고, 거절하면 장소를 직접 선택하게 해줘”라고 요청하세요.

## 동작 확인

1. 실제 지도가 표시되나요?
2. 마커가 의도한 장소에 있나요?
3. 마커를 누르면 올바른 이름이 나오나요?
4. 장소 선택 기능을 추가했다면 다른 장소로 이동하나요?

위도·경도는 날씨 API의 격자 좌표와 다릅니다. 연결 실패 시 실제 화면의 오류와 현재 접속 주소를 함께 확인하세요.
