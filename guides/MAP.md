# 지도·위치정보 구현하기

서비스에 필요한 장소를 지도에서 보여주는 기능입니다. 장소 검색, 모임 위치, 캠퍼스 시설 안내 등에 사용할 수 있습니다.

## 준비

- 수정할 곳: `starter/index.html`의 `map` 영역.
- 기존 발표에서는 Google Maps JavaScript API를 사용했습니다. API 사용 설정, 지도 키, 허용 사이트 설정이 필요합니다.
- 기존 예제는 결제 계정 설정과 사용량에 따른 비용 확인이 포함됩니다. 설정 전에 [지도 설정 문서](../docs/MAPS.md)를 확인하세요.

## Codex 요청문

```text
starter의 지도·위치정보 영역에 Google 지도를 구현해줘.
서울대학교 정문 위치에 마커를 표시하고,
마커를 누르면 장소 이름이 보이게 해줘.
docs/MAPS.md를 참고해서 필요한 API 설정과 비용 발생 가능성을 먼저 설명해줘.
좌표는 확인한 실제 위치를 사용하고, 설정할 항목과 확인 방법을 안내해줘.
```

## 내 아이디어로 바꾸기

- 서울대학교 정문을 내 서비스에서 필요한 장소로 바꿉니다.
- 여러 장소가 필요하면 “장소 목록에서 선택할 때 지도와 마커도 이동하게 해줘”라고 이어서 요청합니다.
- **사용자의 현재 위치**는 별도 기능입니다. 필요할 때만 “위치 사용에 동의하면 현재 위치를 보여주고, 거절하면 장소를 직접 선택하게 해줘”라고 요청하세요.

## 동작 확인

1. 실제 지도가 표시되나요?
2. 마커가 의도한 장소에 있나요?
3. 마커를 누르면 올바른 이름이 나오나요?
4. 장소 선택 기능을 추가했다면 다른 장소로 이동하나요?

위도·경도는 날씨 API의 격자 좌표와 다릅니다. 연결 실패 시 실제 화면의 오류와 현재 접속 주소를 함께 확인하세요.
