# 막혔을 때

## 화면을 열 수 없어요

| 상황 | 확인할 것 |
| --- | --- |
| ZIP 안에서 열었어요 | 압축을 모두 푼 뒤 `starter/index.html`을 다시 엽니다. |
| 파일에 글자만 보여요 | `index.html`을 코드 편집기가 아닌 브라우저로 엽니다. |
| npm 또는 node를 찾을 수 없어요 | Node.js 20 이상을 설치하고 앱·터미널을 다시 엽니다. 화면 확인만 필요하면 직접 열기를 사용합니다. |
| package.json을 찾을 수 없어요 | `starter` 안이 아닌, README와 package.json이 있는 저장소 폴더에서 실행합니다. |
| PowerShell에서 npm.ps1 실행이 차단돼요 | 같은 폴더에서 `npm.cmd run dev`를 사용합니다. |
| 주소에 연결할 수 없어요 | `npm run dev`를 실행한 터미널이 켜져 있는지 확인합니다. |
| 5173이 이미 사용 중이에요 | 이 실습에서 먼저 켜둔 서버를 찾아 `Ctrl+C`로 종료한 뒤 다시 실행합니다. 모르는 프로그램은 종료하지 말고 Codex에 다른 포트 사용을 요청하세요. |
| 바꿨는데 화면은 그대로예요 | 파일 저장 후 새로고침합니다. 공유 예제가 아닌 내 로컬 화면을 보고 있는지 확인합니다. |
| 요청문 복사가 안 돼요 | 복사 버튼을 누르면 요청문이 선택됩니다. `Ctrl+C` 또는 `⌘C`로 복사하세요. 직접 드래그해도 됩니다. |

## API 기능이 동작하지 않아요

처음 제공한 기초 틀은 기능이 들어갈 자리만 있습니다. 실제 기능을 구현한 뒤에는 필요한 서버 실행, 개인별 키 설정, 외부 서비스의 앱 주소 설정도 확인해야 합니다. [로그인](LOGIN.md) · [지도](MAP.md) · [날씨](WEATHER.md)의 동작 확인 순서를 보세요.

## Codex에 오류 설명하기

```text
내가 한 일: [어떤 요청과 설정을 했는지]
기대한 결과: [어떤 화면이나 동작을 기대했는지]
실제 결과: [무엇이 보이는지]
오류 문구: [화면이나 터미널의 오류]

원인을 먼저 확인하고, 필요한 부분만 고쳐줘.
다시 확인할 방법도 알려줘.
```

스크린샷을 함께 보여줘도 됩니다. 비밀키·비밀번호는 가리세요.
