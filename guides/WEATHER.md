# 날씨 기능 구현하기

내 서비스에서 필요한 지역과 시간의 날씨를 가져오는 기능입니다. 예시는 기상청 단기예보의 기온과 강수확률입니다.

## 준비

- 수정할 곳: `starter/index.html`의 `weather` 영역.
- 공공데이터포털의 기상청 단기예보 API 이용 신청과 본인 인증키가 필요합니다.
- 키를 보관하고 날씨를 요청할 서버가 필요합니다. 초기 기초 틀의 로컬 서버는 화면 파일만 제공하므로, API 기능은 Codex와 추가해야 합니다.
- 기존 구현과 설정은 [날씨 설정 문서](../docs/WEATHER.md)를 참고하세요.

## Codex 요청문

```text
starter의 날씨 영역에 기상청 단기예보 API를 연결해줘.
관악구 대학동의 내일 오후 6시 기온과 강수확률을 보여줘.
docs/WEATHER.md와 기존 서버 예제를 참고해 필요한 서버 기능을 추가해줘.
인증키는 서버의 KMA_SERVICE_KEY로 관리하고, 내가 직접 입력할 위치를 안내해줘.
로딩·조회 실패·예보 없음 상태와 재시도를 넣어줘.
실제 API 응답과 화면에 표시된 날짜·시간·값을 비교하는 방법도 알려줘.
```

실제 인증키를 AI 대화, 공개 HTML/JavaScript, GitHub에 넣지 마세요. 안내받은 로컬 서버 설정에 직접 입력합니다.

## 내 아이디어로 바꾸기

- ‘관악구 대학동’을 필요한 지역으로 바꾸고, 그 지역에 맞는 조회 좌표도 함께 바꾸도록 요청합니다.
- ‘내일 오후 6시’를 서비스에서 필요한 시간으로 바꿉니다. 예보가 제공되지 않는 날짜는 ‘예보 없음’으로 표시해야 합니다.
- 지역 이름만 바꾸고 데이터는 그대로 남지 않았는지 확인하세요.
