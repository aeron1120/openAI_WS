# 로그인 기능 구현하기

사용자가 누구인지 확인하고, 이름이나 프로필을 보여주는 기능입니다. 내 서비스에 사용자 구분이 필요할 때 선택하세요.

## 준비

- 수정할 곳: `starter/index.html`의 `login` 영역.
- 기존 발표에서는 Google 로그인을 사용했습니다. 앱 등록, 클라이언트 ID, 로그인 결과를 검증하고 상태를 유지할 서버 또는 인증 서비스가 필요합니다.
- 자세한 기존 예제 설정은 [로그인 설정 문서](../docs/AUTH.md)를 참고하세요. 기초 틀에 서버 기능은 아직 없습니다.

## Codex 요청문

```text
starter의 로그인 영역에 Google 로그인 기능을 구현해줘.
로그인하면 이름과 프로필 사진을 보여주고,
새로고침해도 로그인 상태가 유지되게 해줘. 로그아웃도 추가해줘.
기존 docs/AUTH.md를 참고하고, 필요한 서버와 Google 설정을 설명해줘.
내가 직접 설정해야 할 항목과 순서를 먼저 알려줘.
실제 로그인 확인 없이 완료됐다고 표시하지 마.
```

## 내 아이디어로 바꾸기

- 박스 위치와 로그인 후 표시할 문구를 바꿔도 됩니다.
- ‘내가 저장한 장소’처럼 개인별 데이터가 필요하다면 **데이터 저장·조회는 로그인과 별도 기능**으로 추가 요청하세요.
- 로그인이 필요 없다면 박스 전체를 삭제하세요.

## 동작 확인

1. 로그인 전에 게스트 상태가 보이나요?
2. 실제 계정을 선택하면 내 이름과 프로필이 보이나요?
3. 새로고침 후에도 같은 계정으로 표시되나요?
4. 로그아웃하면 다시 게스트로 돌아오나요?

실패하면 접속한 주소와 등록한 앱 주소가 맞는지, 필요한 서버가 실행 중인지 Codex와 확인하세요.
