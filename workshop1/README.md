# Workshop 1 · 기존 발표용 모임 앱

날씨 → Google 로그인 → 지도 기능을 연결한 캠퍼스 모임 앱입니다.

**새로 실습을 시작하는 학생은 [starter/](../starter/README.md)로 가세요.** 이 폴더는 기존 예제를 참고하거나 운영하는 데 사용합니다.

| 찾는 내용 | 파일 |
| --- | --- |
| 화면과 배치 | `index.html`, `styles.css` |
| 모임 선택 등 공통 동작 | `app.js` |
| 날씨 / 로그인 / 지도 | `weather.mjs` / `auth.mjs` / `maps.mjs` |
| 예제 모임 정보 | `meetings.mjs` |
| 발표 단계 표시 | `version.mjs`, `versions.html` |
| 이미지와 글꼴 | `assets/` |

[단계별 예제와 확인 상태](../guides/EXAMPLES.md) · [배포 기록](../docs/WORKSHOP1-DEPLOYMENTS.md)

로컬 서버 예제 실행: 저장소 루트에서 `npm run dev:workshop1`. 설정은 [날씨](../docs/WEATHER.md), [로그인](../docs/AUTH.md), [지도](../docs/MAPS.md)를 참고하세요.
