# 여기가 내가 수정할 웹사이트입니다

기능을 넣을 자리는 준비되어 있고, 실제 로그인·지도·날씨는 아직 구현하지 않았습니다.

| 파일 | 바꾸는 내용 |
| --- | --- |
| `index.html` | 사이트 이름·소개, 박스의 내용과 순서, 요청문 |
| `styles.css` | 색, 크기, 박스 배치, 모바일 화면 |
| `app.js` | 요청문 복사, 앞으로 추가할 기능의 동작 |

**화면만 보기:** 이 폴더의 `index.html`을 브라우저로 여세요.

**Codex와 수정하기:** 저장소 전체 폴더를 열어야 공통 시작 안내와 예제도 참고할 수 있습니다. [처음 준비하기](../guides/START-HERE.md)를 따라 하세요.

## 화면과 코드의 이름

| 보이는 공간 | HTML에서 찾을 이름 | CSS에서 찾을 이름 |
| --- | --- | --- |
| 로그인 | `id="login"` | `.login` |
| 지도·위치정보 | `id="map"` | `.map` |
| 날씨 | `id="weather"` | `.weather` |
| 나만의 기능 | `id="custom"` | `.custom` |

직접 코드를 찾을 필요 없이 “로그인 박스를 왼쪽으로 옮겨줘”처럼 요청해도 됩니다. 각 `section`은 하나의 기능 박스입니다. 필요 없는 `section`은 통째로 삭제하거나 이동해도 나머지 요청문 복사는 계속 동작합니다.

기능이 늘어나면 `features/`, 이미지가 필요하면 `assets/` 같은 하위 폴더를 추가할 수 있습니다. 파일 이름은 `my-map.js`, `campus-photo.png`처럼 영문·숫자·하이픈을 사용하세요. 새 파일은 HTML에서 연결해 주세요.
